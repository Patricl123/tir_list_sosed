# Соседи по общаге 🏡

Интерактивный тир-лист типажей соседей: с кем жить в одной комнате, а кого отправить на переселение? Весёлый студенческий проект на React, TypeScript и Vite. Работает без регистрации, сервера, платных API и внешних сервисов.

## Что умеет

- 16 готовых типажей и пять цветных уровней S–D.
- Перетаскивание между уровнями, изменение порядка и возврат в общий набор.
- Выбор уровня нажатием на карточку на телефоне; управление с клавиатуры через Tab, Enter и Escape. В меню карточки есть кнопки изменения порядка.
- Создание своего типажа с названием (до 48 символов) и эмодзи; всего до 100 карточек.
- Автосохранение в `localStorage` и восстановление после перезагрузки. Данные остаются только в текущем браузере. Если хранилище недоступно, сайт показывает предупреждение.
- Экспорт заголовка и текущих пяти уровней в PNG высокого разрешения через Canvas; кнопки и нераспределённые карточки в картинку не попадают.
- Сброс с подтверждением: восстановит 16 исходных карточек и удалит пользовательские типажи.
- Мобильная версия, доступные диалоги, учёт настройки уменьшения анимации.

## Установка и запуск

Нужен Node.js 22.12+ (подходит Node.js 24) и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite, обычно **http://127.0.0.1:5173/**.
В Windows PowerShell с ограничением запуска скриптов используйте `npm.cmd` вместо `npm`.

## Сборка

```sh
npm run build
npm run preview
```

Сборка с проверкой TypeScript создаётся в `dist/`. Предпросмотр обычно доступен на http://127.0.0.1:4173/.

## Проверка

```sh
npx playwright install chromium
npm test
```

Локально тесты используют установленный Google Chrome. Чтобы использовать загруженный Chromium, запустите с переменной `CI=1` (в PowerShell: `$env:CI='1'; npm.cmd test`).
Playwright проверяет перенос мышью, перестановку, назначение с клавиатуры и на мобильном экране, сохранение после перезагрузки, свои типажи, подтверждение сброса, PNG и отсутствие горизонтальной прокрутки.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` при каждом push в `main` устанавливает зависимости, выполняет браузерные тесты, собирает приложение и публикует `dist/` через GitHub Actions. Его можно запустить вручную через **Actions → Run workflow**.

В **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**.
`vite.config.ts` автоматически берёт имя репозитория из `GITHUB_REPOSITORY` и устанавливает `base` в `/<имя-репозитория>/`. При смене имени репозитория конфигурацию менять не нужно. Локально используется `/`.

В репозиторий входят исходники, lock-файл, документация и workflow. `node_modules`, `dist`, `.env`, временные инструменты и результаты тестов исключены через `.gitignore`. Секреты и токены приложению не нужны.
